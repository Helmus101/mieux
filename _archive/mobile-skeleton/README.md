# FoodIQ Mobile App

Expo React Native mobile application for FoodIQ with TypeScript.

## Setup

```bash
npm install
npm start
```

## Features

- Expo SDK 50
- React Native 0.73
- Expo Router for navigation
- TypeScript
- Shared code with web app
- Camera support via expo-camera

## Platforms

- iOS (primary)
- Android (future)
